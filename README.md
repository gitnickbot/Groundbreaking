# GroundBreaking

A team-based, tap-to-dig race to the centre of the Earth. This repository hosts the online playtest build.

**Play:** https://gitnickbot.github.io/groundbreaking/ (best in Safari or Chrome on a phone)

- `index.html` is the whole game in one page: art, sound and code included.
- Accounts, teams, chat, hard seams and raids run on a Supabase game server. The key in the page is a publishable key, which is meant to be public; the server's own rules decide what each player can do.
- To update the game, replace `index.html` with a new build.
